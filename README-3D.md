# Word Mashup 3D

WebGL(three.js) 3D 버전. 원본 `jinilee-hue/phonics-wordmashup`(@3f32c16)을 복제한 별도 저장소이며, 원본은 건드리지 않는다.

## 실행
- `실행.command` 더블클릭 → http://127.0.0.1:5183/
- 또는 `npm install && npx vite --port 5183`

## 구조
- Phaser 캔버스를 투명하게 두고, 그 아래에 three.js 캔버스(`src/gl/`)를 깐다.
- Phaser가 규칙·입력·HUD·팝업·이펙트를 그대로 맡는다. 3D 층은 매 프레임 Phaser 객체(카드 위치·크기·알파, 존 위치)를 읽어 그린다.
  - `src/gl/stage.ts` — 렌더러·카메라(z=0 평면이 Phaser 좌표와 1:1)·배경·조명·패럴랙스
    - 주 조명은 화면 가운데 위 앞쪽. 왼쪽 카드는 오른쪽으로, 오른쪽 카드는 왼쪽으로 돌아 있어서 조명이 한쪽에 치우치면 한 줄이 어두워진다(오른쪽 위에 두었을 때 오른쪽 카드가 약 10% 어두웠음).
  - `src/gl/cards3d.ts` — 두께 있는 점토 카드(앞면 = 펴낸 카드 그림), 떠다님·기울기·들어올림·그림자·힌트
    - 카드 각도는 화면 축이 아니라 '카메라에서 카드를 보는 방향' 기준이라 어느 자리에 있어도 같은 각도로 보인다(원본 그림처럼).
      기본값 돌림 28°·뒤로 젖힘 10°·두께 30은 원본 그림의 옆벽·아랫벽 두께와 기울기에 맞춘 값(`tools/qa/pose_fit.py`).
    - 모서리: 앞면 그림·카드 몸통·베벨이 같은 원호 모서리(`FACE_RADIUS`, 원본 그림에서 잰 값)를 쓴다. 그림자·힌트 빛은 카드보다 먼저 그려서 카드 위로 덮이지 않는다.
  - `src/gl/zone3d.ts` — Gravity Zone(인트로 영상과 같은 모양): 무대 위에 떠 있는 진한 남보라 원판, 분홍 네온 링(안쪽 얇은 라벤더 링, 링 둘레 플라스마 줄기·반짝이), 흰 'Gravity / Zone' 글자. 배경 그림의 바닥 네온 링에서 반짝이가 올라온다. 판이 시작될 때와 공간 이동 뒤에 바닥에서 솟아오른다.
  - `src/gl/travel.ts` — 라운드 사이 공간 이동(인트로 영상처럼): 정답 후 카메라가 존을 지나 배경의 아치 게이트 쪽으로 다가가고(배경이 깊이 부조라 시차가 생김) 글리가 포털로 뛰어듦 → 하얀 섬광 → 인트로 영상의 비행 장면(1.0–2.4초: 떠 있는 섬들 위를 낮게 날아 무대로 내려앉음)이 배경으로 재생되고, 영상의 마지막 장면이 게임 배경 그림과 같아서(상관 0.95) 짧게 겹쳐 그림으로 넘어감(색은 그림에 맞춰 보정) → 존이 솟아오르고 다음 카드들이 양옆에서 날아와 자리에 앉음. 영상을 못 쓰면 카메라가 게이트에서 물러나는 방식으로 대신한다. 바이트 범위를 지원하지 않는 호스트에서는 영상을 통째로 받아 쓴다(개발 서버는 지원). 이동 중에는 입력을 막는다. 움직임 줄이기(reduced motion) 설정이면 원래처럼 옆에서 미끄러져 들어온다.
  - `src/gl/mashup.ts` — 카드 충돌(인트로 영상과 같은 연출): 두 카드가 V자로 맞닿으며 부딪히면 구름 덩어리가 연기 꼬리를 끌며 양옆·아래로 터지고, 사탕색 줄기·입체 별·색 구슬이 튀며 카드가 그 안에서 들썩인다 → 구름이 걷히고 두 카드가 맞밀고 있다 → 두 번째 펑(구름 더미가 카드를 덮고 바깥으로 날아감) → 가운데서 합성어 카드가 작게 시작해 커지고, 뒤에서 금빛 빛무리·회전 빛살·구슬 비가 카드가 사라질 때까지 이어진다. 점수·결과 카드·타이밍 규칙은 Phaser 그대로이고, 2D 모드에서는 원래 연출이 나온다.
  - `src/gl/reward.ts` — 점수 보상(인트로 영상처럼): 결과 카드가 나오면 별·코인·보석이 카드 아래에서 튀어나와 호를 그리며 퍼졌다가(별은 돌고, 코인은 뒤집히고, 보석은 흔들리며 반짝이 꼬리를 남김) 카드 아래 '+10 / +15 / +3' 칩으로 빨려 들어가고 칩 숫자가 올라간다 → 칩 아이콘이 위쪽 점수판으로 날아가 닿는 순간 점수판 숫자가 올라간다(원래의 countUp·bumpBadge를 그때로 미룸). HUD 층(Phaser)에 그린다. 2D 모드와 움직임 줄이기 설정에서는 원래 연출.
  - `src/gl/index.ts` — 품질 단계(high/mid/low), 느리면 단계 하향, 최후에는 2D로 복귀
  - `src/gl/glee.ts` — 튜터 캐릭터 글리(Glee, 캐릭터 시트 기준). 몸통·팔·다리를 거리장(SDF)으로 만들어 셰이더에서 레이마칭하고 부드럽게 합쳐서 이음새가 없다. 얼굴(눈·입·볼터치·눈썹·눈물)은 셰이더로 그리고, 글리터는 몸 안의 반짝이 점들이다.
    - 자리: 둥근 무대 왼쪽 앞(디자인 좌표 1280x720 기준 발 위치 445, 640 / 키 125). 카드·결과 카드·버튼과 겹치지 않는 자리이고, 가운데를 보도록 살짝 돌아서 있다.
    - 고정 카메라로 그리는 오버레이 단계(`stage.overlay`)에 있어서 패럴랙스나 공간 이동 중에도 화면의 같은 자리에 있다.
    - 반응: 시작 인사(손 흔들기), 카드를 잡으면 그 카드를 봄, 존에 넣으면 끄덕, 오답이면 슬픔(눈물·땀방울) 후 격려, 정답이면 환호(점프·하트·별), 힌트를 누르면 정답 카드를 차례로 가리킴, 마지막 화면에서 계속 환호.
    - 공간 이동 때 달리기(이동 시계로 구동): 등을 돌려 분홍 길을 따라 존까지 달려가 포털로 뛰어들고(카메라가 뒤따라감, 섬광 속에 사라짐) → 도착 영상이 끝나고 존이 솟으면 포털에서 튀어나와 플레이어 쪽을 보며 제자리로 달려옴 → 360도 한 바퀴 돌고 착지. 발걸음마다 먼지 구름. 움직임 줄이기 설정이면 이동 자체가 없어서 달리지 않는다.
    - 포인터(할리갈리 핑크벨 방식): 마우스·손가락 쪽으로 몸과 눈을 돌린다. 잡고 돌리면 손을 따라 돌고, 놓으면 그 속도로 미끄러지다 가장 가까운 정면으로 돌아온다. 아래로 끌면 공중제비, 콕 찌르면 찌그러지며 뛴다. 글리를 잡는 동안 카드는 잡히지 않는다.
    - 몸 색: 위는 노랑, 아래는 민트(2026-10-27 시안 중 선택). 캐릭터 시트의 핑크·파스텔은 분홍·보라 네온 무대와 섞여 잘 안 보였다. 글리터도 같은 계열로 맞췄다.
    - 테두리 선 없음(검은 외곽선 대신 몸빛 가장자리). 가장자리는 한 픽셀 안을 4개 광선(낮은 품질은 2개)으로 나눠 쏘아 계단 없이 매끄럽게 그린다.
    - 2D 모드(`?q=2d`, 느린 기기 폴백)에는 나오지 않는다.
  - `src/gl/tutor.ts` — 글리가 말로 게임을 이끈다(말풍선·글자 없이 음성만, 정해진 영어 문장 + 브라우저 음성 인식. 조직 정책상 LLM 대화는 쓰지 않음). 한 번에 한 명만 말하고, 아이가 움직이면 글리가 말을 멈춘다. 듣는 동안은 머리 옆에 민트 귀 아이콘만 보인다(뒤에 배지 없이 배경이 비침, 몸의 민트와 같은 계열).
    - 라운드: "Which two go together?" → 듣기 → 카드 단어를 말하면 그 카드를 넣고 "What goes with pan?" → 맞으면 "Pan and cake make... pancake!" → "Say it with me!" → 못 알아들으면 "Listen! Pan! Cake! Pancake! Your turn!" → 칭찬 → 다음 판.
    - 오답(글자 토스트 대신 음성): 두 카드를 읽고 "That's not a word!" → 한 장이 맞았으면 "Pan is right!" 하며 그 카드를 다시 넣고 짝을 묻는다. 둘 다 틀리면 1번째 "Let's try again!", 2번째 첫 카드를 보여 주고 넣은 뒤 짝을 묻는다, 3번째 힌트. 원래 Mic 버튼의 한국어 안내도 글리 목소리로 바뀐다.
    - 음성: `tools/build_glee_voice.py`(edge-tts `en-US-AnaNeural` +10Hz −5%, 시제품용) → `public/gl/voice/*.mp3`, `src/gl/gleeVoice.ts`(입 모양·단어 시각). `?tutor=off`면 끈다. 파일 주소에 `?v=<목소리>`가 붙어 목소리를 바꾸면 캐시된 옛 목소리가 나오지 않는다.
      Jenny(+15Hz)로 바꿨다가 Ana로 되돌렸다(사용자: "목소리는 Ana가 나아"). 참고: Whisper 언어 판별로 한 단어 대사 80개 중 Ana는 65개만 영어(중국어 4, 일본어 9), Jenny는 80개 모두 영어였다. 목소리를 바꿀 때는 먼저 들려 주고 정한다.
- 배경 깊이: `tools/build_depth.py`가 배경 그림의 깊이 지도(Depth Anything V2 Small, 로컬 CPU)를 만들어 `public/gl/bg_depth.png`에 저장 → 배경이 입체 부조가 되어 카메라가 움직이면 시차가 생긴다(정지 화면은 원본과 똑같다).
  - 실행: `uv run --with torch --with transformers --with pillow --with numpy python tools/build_depth.py`
- 인트로 영상(`Word Mashup/Word Mashup.mp4`): 오른쪽 아래 Gemini(Veo) 반짝이 마크를 지운 판. 마크가 반투명하게 섞인 식을 거꾸로 풀어 원래 화면을 되살렸다(지우개로 칠한 것이 아님). 마크 모양은 GeminiWatermarkTool(MIT, allenk)의 보정 마스크에서 시작해, 이 영상의 평평한 장면에서 잰 값으로 고쳤다(영상 마크는 가운데가 테두리보다 15% 옅다). 안쪽 세기는 프레임마다 둘레 밝기에 맞추고, 별 테두리 2~3px에 남는 약한 계단만 지운 뒤 바깥에서 다시 이어 붙였다(Poisson). 테두리에 남는 1~2px 점도 지운다. 만드는 스크립트: 세션 scratch `wm/wmk/veo_v7.py`. 마크 밖 화면과 소리는 그대로(재인코딩만). 마크가 있던 원래 영상은 git 기록(`a489ef7` 이전)과 원본 저장소에 있다.
- 카드 앞면: `tools/unwarp_cards.py`가 원본 카드 그림(기울기·두께가 그려진 PNG)에서 앞면만 찾아 정면으로 편다 → `public/gl/cards/*.webp`, `src/gl/cardFaces.ts`.
  - 실행: `uv run --with pillow --with numpy python tools/unwarp_cards.py [--debug DIR]`
  - 텍스처는 불투명: 모양은 3D 앞면 도형이 자르고, 가장자리 5px은 안쪽 색으로 다시 채운다(벽색·번짐 제거). 실행하면 그림 모서리 반지름 측정값도 출력한다.

## URL 옵션
- `?q=high|mid|low|2d` 품질 고정 (`2d` = 원본 2D)
- `?fps` 프레임 표시
- `?cal` 카드를 정면으로 고정(조명 보정용)
- `?pose=돌림,젖힘,화면기울기비율,두께` 카드 각도 비교용 (예: `?pose=28,10,1,30`)
- `?glee=off` 글리 끄기

## 배경 A안 시험 (기본 화면은 그대로)
- `?bg=layers`: 배경 그림을 깊이별 4층(하늘, 먼 섬·풍선·게이트·구름, 바닥·옆 발판, 앞 구름)으로 나눠 각 층을 자기 깊이의 입체판으로 그린다. 앞 층이 가리던 부분은 미리 채워 두었다(하늘: 주변 하늘색으로 부드럽게, 섬·바닥 뒤: LaMa 로컬 인페인팅). 파일은 `public/gl/layers/`(약 410KB). 멈춘 화면은 원래 그림과 같다(합성 PSNR 43dB). 만든 스크립트는 아직 저장소 밖(scratch)에 있어서, A안을 쓰기로 하면 `tools/`로 옮긴다.
- `?fly=1`: 배경 시연 비행. 11초 반복(정지, 왼쪽, 오른쪽, 게이트 쪽으로 들어갔다 나옴). 지금 방식은 `?fly=1`, A안은 `?bg=layers&fly=1`로 비교한다. 들어가는 깊이는 게이트까지의 35%다. 시험 비행에서 37% 정도까지는 그림이 버티고 45%를 넘으면 번졌다. 날아가는 동안 게임 입력은 카메라를 따라가지 않는다.
